# Raqib · HR policy compliance

**Aonami entry for the Emirates Group challenge on Ignyte.**

Every HR transaction, checked against every written rule. Each exception explained with its rule and evidence, routed to an owner, and decided by a person.

**Demo video (under 3 minutes):** https://loom.com/share/7807ee4d4aeb47d9a1ca47ab179bfbbf

**Live prototype:** https://aonami-raqib.vercel.app. It is hosted, needs no install, and runs entirely in your browser with no cloud AI. Press **Guided demo** for a walk-through.

## Results on our held-out test set

| Measure | Result |
|---|---|
| Planted violations found | 440 of 440 |
| False positives | 0 |
| Near misses wrongly flagged | 0 of 170 |
| Run time, 9,744 transactions × 18 rules | 52 ms |

> **Data limitation.** The official data pack and test files were not available, so we curated a synthetic sample in the exact shape the brief describes. We generated it with seed 2310, which was never used while building, held back its answer key, ran the prototype on it, and scored the result. These results show how the approach performs on that sample. They are not results on Emirates data.
> The prototype loads the official files the same way: column names are matched by meaning, and other date formats load unchanged.

## Responsible AI, in one line

Raqib recommends and a person decides. Nothing is changed or written back automatically, and every result shows the rule, the data or the evidence behind it.

## Data

All data here is synthetic and was generated by Aonami. There is no real employee data. Emirates Group is named only as the challenge host; no endorsement is implied.
